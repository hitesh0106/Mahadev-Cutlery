# PRODUCT IMPORT GUIDE — MAHADEV CUTLERY & GIFT ARTICLES

How to turn the classification system into real Shopify products — honestly, with
no invented data. Files: `data/product-import-template.csv` (canonical template,
also downloadable as `/api/products-csv` and `/api/products-xlsx`),
`data/brand-department-map.csv`, `data/department-collection-seed.csv`.

---

## 1. Files

| File | Purpose |
|------|---------|
| `data/product-import-template.csv` | Shopify-compatible product-import CSV (30 canonical columns). Contains **example rows only**, clearly marked `EXAMPLE — DELETE BEFORE IMPORT`, published = FALSE, status = draft so an accidental import cannot reach the storefront. |
| `/api/products-csv` | The same template generated by the app (UTF-8 BOM + CRLF for Excel). |
| `/api/products-xlsx` | Excel workbook: Import sheet (dropdown validation for Vendor/Type), hidden Lists sheet, Reference sheet with the brand rules and tag conventions. |
| `data/brand-department-map.csv` | 30 brand profiles: allowed departments, types, customer groups, prohibited classifications, verification status. |
| `data/department-collection-seed.csv` | The eight department collections with handles, automated conditions, suggested combined collections and filters. |

## 2. Required fields per product

Title · Handle · Description (Body HTML) · Vendor (brand) · Product Category
(Shopify standard taxonomy — optional, never guessed) · Product type · Tags
(`department_*`, `audience_*`, `type_*`, `brand_*`, `gf-*` where applicable) ·
Variants/options (Size, Colour…) · Actual price · Compare-at price (only if a
genuine before-price exists) · Inventory · Image URLs (real, owned/authorized) ·
SKU and barcode when supplied · Metafields where supported
(`custom.department`, `custom.subcategory`, `custom.audience`).

## 3. Validation rules (checked before import)

1. **Vendor** must be one of the canonical spellings in
   `data/brand-department-map.csv` (e.g. `L'Oréal Paris`, `L'Oréal Professionnel`,
   `Lakmé`, `MARS Cosmetics`, `POND'S`). No duplicates or spelling variants.
2. **Type** must match an allowed product type for that brand+department.
3. **Department tag** must be one of the eight approved departments — there is
   no kitchenware/cutlery department.
4. **Brand restrictions enforced:** Zoiro → men only; Bodycare → women/boys/girls
   only (never men); Lady Care → women only; Lotus Herbals → never auto-classified
   as makeup; L'Oréal Paris ≠ L'Oréal Professionnel; Sunny → every product
   stock-verified; Ghar Soaps → brand identity verified first.
5. **No invented data:** SKUs, barcodes, inventory, prices, images, ratings,
   reviews, discounts, stock quantities, bestseller ranks, ingredients, warranty
   terms or delivery promises are never fabricated. Empty where unknown.
6. **Example rows** are deleted before any real import.
7. **Compare-at** only with a genuine before-price; otherwise left empty.
8. **Image Src** left empty unless the URL is real and authorized — never scraped
   product photography.

## 4. Import workflow

1. Download the XLSX (or CSV) template.
2. Fill one row per variant; option **names** only on the product's first row.
   Handle = one dash-separated id repeated on every row of that product.
3. Vendor from the dropdown; Type from the dropdown; add the four tag families
   plus `gf-*` tags if the product should appear in the Gift Finder.
4. Delete ALL example rows and the banner row (XLSX).
5. Save as **CSV UTF-8** (Excel: File → Save As → CSV UTF-8).
6. Shopify Admin → **Products → Import** → Add file → Upload and continue →
   **Preview** → **Import products**.
7. Spot-check imported products: title, vendor, type, tags, price, images, inventory.
8. Publish to the Online Store channel (products start as draft — publish only
   verified items).

## 5. Collections after import

Create the eight department collections with the conditions in
`data/department-collection-seed.csv`, then brand collections
(*Product vendor is X*) only for brands with real stock, then any brand+
department or seasonal collections that real products qualify for. The theme
links only to collections the merchant selects — empty collections can simply be
left unlinked.

## 6. Product verification workflow (PART 11)

For each product, verify: ① exact brand → ② exact product name → ③ actual
product type → ④ correct department → ⑤ intended customer group (where
applicable) → ⑥ size/variant → ⑦ actual selling price → ⑧ actual inventory →
⑨ genuine product image → ⑩ product-specific details.
If a field cannot be verified: leave it empty where appropriate, mark it as
needing verification, never invent a value, never publish unsupported claims.
Manufacturer catalogues may help identify possible product types — they do NOT
prove the store stocks the product; stock and price are always confirmed by the
merchant.
